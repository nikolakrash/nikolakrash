Оплата по СБП через T-Bank

Быстрая оплата TeleBoosting по СБП

Мы подготовили отдельную страницу оплаты в стиле TeleBoosting. Для завершения платежа откроется защищённая страница T-Bank, где можно оплатить заказ через СБП.

Перейти к оплате по СБП Вернуться к тарифам
Защищённый сценарий Платёж открывается на стороне T-Bank, без ввода данных на сайте TeleBoosting.
Оплата через СБП Покупатель оплачивает в приложении банка по стандартному СБП-сценарию.
Подходит для мобильных На телефоне переход ведёт к удобному сценарию оплаты через банковское приложение.
TeleBoosting
СБП
После перехода откроется банковская страница оплаты. Если T-Bank покажет QR, его можно отсканировать из банковского приложения. На мобильном обычно доступен прямой сценарий оплаты.
1
Нажмите кнопку оплаты
Откроется официальная страница T-Bank для оплаты по СБП.
2
Подтвердите платёж
Выберите удобный банковский сценарий и завершите оплату в приложении банка.
3
Вернитесь к работе
После оплаты можно вернуться к TeleBoosting и продолжить работу с лицензией.
Если страница оплаты не открылась автоматически в банковском приложении, используйте кнопку перехода и завершите платёж вручную на стороне T-Bank.
