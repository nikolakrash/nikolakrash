Эта страница каждый раз создаёт новый тестовый платёж через API T-Bank, поэтому форму можно проходить повторно разными тестовыми картами.

Создаём новый тестовый платёж...
  • Новый OrderId генерируется автоматически при каждом открытии страницы.
  • Сумма тестового платежа: 100 ₽.
  • После успешной оплаты можно сразу создать ещё один тестовый счёт.
