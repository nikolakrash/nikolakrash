Выбрать устройство с параметрами из базы - Заранее можно сгенерировать базу параметров для Desktop версии (Версия ОС, Версия Telegram Desktop, Разрешение экрана, RAM)

Массовый импорт session+json

Нажмите "Выбрать папку" для выбора папки через проводник Windows. В папке должны находиться подпапки с номерами телефонов (например, 77075247083, 77075247084 и т.д.).

⚠️ Требуется браузер Chrome или Edge для работы проводника Windows или Mac.

Режим распределения прокси

  • По порядку из добавленного списка - прокси в системе
  • В рандомном порядке
  • По гео
  • Выбрать из списка (несколько, по кругу)
  • Выбрать прокси из папки - должны быть заранее добавлены прокси в модуль "Прокси" и распределены по папкам.

Панель аккаунтов

Панель действий с аккаунтами появляется в менеджере аккаунтов после выбора одного или нескольких аккаунтов (через чекбоксы). Все действия применяются к выбранным аккаунтам одновременно, что позволяет эффективно управлять большим количеством аккаунтов. Можно вызвать контекстное меню нажатием правой кнопки мыши по аккаунту.

⚙️ ДЕЙСТВИЯ С ПРОФИЛЕМ

ОПИСАНИЕ:

Открывает модальное окно с набором инструментов для управления профилями выбранных аккаунтов. Это комплексный инструмент для работы с данными Telegram-аккаунтов.

ДОСТУПНЫЕ ДЕЙСТВИЯ:

  • Заполнить профиль
    • Автоматическое заполнение имени, фамилии, биографии и фото профиля
    • Можно задать общие данные для всех выбранных аккаунтов
    • Полезно для быстрой настройки новых аккаунтов
  • Опубликовать/Удалить историю
    • Публикация Stories (историй) в выбранных аккаунтах
    • Поддержка одного файла для всех или разных файлов для каждого аккаунта
    • Возможность удаления существующих историй
  • Получить код авторизации
    • Мониторинг и получение кодов авторизации для выбранных аккаунтов
    • Полезно при восстановлении доступа или авторизации на новых устройствах
  • 2FA (Двухфакторная аутентификация)
    • Установка случайного пароля 2FA
    • Установка собственного пароля 2FA вручную
    • Удаление 2FA с аккаунтов
  • Снятие спамблока
    • Автоматическое взаимодействие с @SpamBot для снятия ограничений
    • Поддержка различных вариантов ответов бота
    • Массовое снятие спамблоков
  • Завершить все сеансы авторизации, кроме этого
    • Безопасное завершение всех активных сессий
    • Оставляет активной только текущую сессию
    • Защита от несанкционированного доступа
  • Очистить все чаты и каналы в профиле
    • Полная очистка истории переписок
    • Удаление всех каналов и групп
    • ⚠️ Внимание: действие необратимо!
  • Удалить данные с профиля
    • Удаление имени, фамилии, биографии, фото, stories

🔑 ПРОВЕРКА API

ОПИСАНИЕ:

Проверяет работоспособность API ключей (API ID и API Hash) для выбранных аккаунтов. Проверка выполняется путем тестового подключения к Telegram API с использованием сохраненных ключей.

ЧТО ПРОВЕРЯЕТ:

  • Корректность API ID и API Hash
  • Доступность API ключей для использования
  • Возможность подключения к Telegram API с данными ключами

РЕЗУЛЬТАТЫ:

  • ✅ "Проверено" (зеленый) - API ключи работают корректно
  • ❌ "Ошибка" (красный) - проблемы с API ключами
  • ⚠️ "Не проверено" (серый) - проверка не была выполнена

✓ ПРОВЕРИТЬ АККАУНТЫ

ОПИСАНИЕ:

Проверяет валидность сессий (tdata) выбранных аккаунтов. Определяет, действительны ли сохраненные сессии авторизации и можно ли использовать аккаунты для работы.

ЧТО ПРОВЕРЯЕТ:

  • Валидность файлов tdata
  • Активность сессий авторизации
  • Возможность подключения к Telegram с текущей сессией
  • Статус авторизации аккаунта

РЕЗУЛЬТАТЫ:

  • ✅ "Действительна" (зеленый) - сессия активна и работает
  • ❌ "Недействительна" (красный) - сессия устарела или повреждена
  • ⚠️ "Не удалось проверить" - ошибка при проверке

РЕКОМЕНДАЦИИ:

  • ✓ Проверяйте аккаунты после длительного простоя
  • ✓ Используйте перед запуском массовых рассылок
  • ✓ Если сессия недействительна - переподключите аккаунт
  • ✓ Регулярная проверка помогает выявить заблокированные аккаунты
  • ✓ Проверка всех аккаунтов может занять время - наберитесь терпения

📡 ПРОВЕРИТЬ ПРОКСИ

ОПИСАНИЕ:

Тестирует работоспособность прокси-серверов для выбранных аккаунтов. Проверяет доступность прокси и возможность подключения через них к Telegram.

ЧТО ПРОВЕРЯЕТ:

  • Доступность прокси-сервера
  • Возможность подключения к Telegram через прокси

РЕЗУЛЬТАТЫ:

  • ✅ "Работает" (зеленый) - прокси функционирует нормально
  • ❌ "Не работает" (красный) - прокси недоступен или неверно настроен

РЕКОМЕНДАЦИИ:

  • ✓ Проверяйте прокси перед массовыми операциями
  • ✓ Регулярно тестируйте прокси на работоспособность
  • ✓ Заменяйте неработающие прокси сразу после обнаружения
  • ✓ Используйте качественные прокси для стабильной работы
  • ✓ Проверка прокси может занять время - не прерывайте процесс
  • ✓ Прокси с таймаутами лучше заменить на более быстрые
  • ✓ Рекомендуем использовать ГЕО прокси под ГЕО аккаунта

🔄 ПРОВЕРИТЬ НА СПАМБЛОК

ОПИСАНИЕ:

Обновляет статус спамблока для выбранных аккаунтов через взаимодействие с официальным ботом @SpamBot. Это наиболее точный способ определения реального статуса аккаунта в Telegram.

ЧТО ПРОВЕРЯЕТ:

  • Наличие временных ограничений (frozen/limited)
  • Наличие вечного спамблока
  • Наличие геоспамблока

РЕЗУЛЬТАТЫ:

  • ✅ "Нет ограничений" (зеленый) - аккаунт полностью активен
  • ❄️ "Заморожен" (оранжевый) - временные ограничения до определенной даты
  • 🚫 "Спамблок" (красный) - вечный спамблок
  • 🌍 "ГеоСпамБлок" (синий) - блокировка при регистрации

РЕКОМЕНДАЦИИ:

  • ✓ Проверяйте статус спамблока регулярно
  • ✓ Используйте перед запуском массовых рассылок
  • ✓ Замороженные аккаунты можно использовать после снятия ограничений
  • ✓ Геоспамблок обычно получают сложные ГЕО
  • ✓ Просматриваете текст сообщения от @spambot в логах, для более точного определения

🌐 УСТАНОВИТЬ ПРОКСИ

ОПИСАНИЕ:

Позволяет массово установить прокси-серверы для выбранных аккаунтов. Поддерживает различные типы прокси и автоматическое распределение по геолокациям.

ВОЗМОЖНОСТИ:

  • Выбор типа прокси: SOCKS5, HTTP, MTProto
  • Установка прокси из системы (если настроена)
  • Автоматическое распределение прокси по GEO
  • Ручной ввод параметров прокси
  • Массовая установка для всех выбранных аккаунтов

ТИПЫ ПРОКСИ:

  • SOCKS5 - универсальный протокол, рекомендуется
  • HTTP - для базовых задач
  • MTProto - специальный протокол Telegram
  • Нет прокси - работа без прокси (не рекомендуется)

РЕКОМЕНДАЦИИ:

  • ✓ Всегда используйте прокси для защиты аккаунтов
  • ✓ Выбирайте прокси из той же страны, что и номер телефона
  • ✓ Используйте качественные резидентные прокси
  • ✓ Регулярно проверяйте работоспособность прокси
  • ✓ Не используйте один прокси для большого количества аккаунтов
  • ✓ Распределяйте аккаунты по разным прокси для безопасности
  • ✓ После установки прокси проверьте его работоспособность

🏷️ УСТАНОВИТЬ СТАТУС

ОПИСАНИЕ:

Позволяет вручную установить статус для выбранных аккаунтов. Используется для маркировки аккаунтов в зависимости от их состояния и для организации работы с ними.

ДОСТУПНЫЕ СТАТУСЫ:

  • Нет ограничений (✅)
  • Заморожен (❄️)
  • Спамблок (вечный) (🚫)
  • ГеоСпамБлок (🌍)

РЕКОМЕНДАЦИИ:

  • ✓ Регулярно обновляйте статусы аккаунтов
  • ✓ Используйте статусы для фильтрации и организации работы
  • ✓ Отслеживайте даты снятия ограничений для замороженных аккаунтов в логах
  • ✓ Статусы помогают планировать работу с аккаунтами
  • ✓ Сочетайте с функцией "Проверить на спамблок" для точности

🗑️ УДАЛИТЬ ВЫБРАННЫЕ

ОПИСАНИЕ:

Удаляет выбранные аккаунты из системы. Удаляются все данные аккаунта, включая tdata, настройки прокси, API ключи и другую информацию. Действие требует подтверждения и является необратимым.

ОТКРЫТЬ В DESKTOP

⚠️ Важно о Telegram Desktop !!!

Сообщения успешно отправляются через софт, но могут не отображаться в открытом окне Telegram Desktop сразу.

Для обновления информации в Telegram Desktop:

  1. Нажмите Ctrl+Shift+Esc (или Ctrl+Alt+Delete → Диспетчер задач)
  2. Найдите все процессы "telegram.exe"
  3. Завершите их (Правой кнопкой → Снять задачу)
  4. Запустите Telegram Desktop заново

После перезапуска все отправленные сообщения будут видны.
