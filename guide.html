🔑 ПРОВЕРКА API

ОПИСАНИЕ:

Проверяет работоспособность API ключей (API ID и API Hash) для выбранных аккаунтов. Проверка выполняется путем тестового подключения к Telegram API с использованием сохраненных ключей.

ЧТО ПРОВЕРЯЕТ:

  • Корректность API ID и API Hash
  • Доступность API ключей для использования
  • Возможность подключения к Telegram API с данными ключами

РЕЗУЛЬТАТЫ:

  • ✅ "Проверено" (зеленый) - API ключи работают корректно
  • ❌ "Ошибка" (красный) - проблемы с API ключами
  • ⚠️ "Не проверено" (серый) - проверка не была выполнена

✓ ПРОВЕРИТЬ АККАУНТЫ

ОПИСАНИЕ:

Проверяет валидность сессий (tdata) выбранных аккаунтов. Определяет, действительны ли сохраненные сессии авторизации и можно ли использовать аккаунты для работы.

ЧТО ПРОВЕРЯЕТ:

  • Валидность файлов tdata
  • Активность сессий авторизации
  • Возможность подключения к Telegram с текущей сессией
  • Статус авторизации аккаунта

РЕЗУЛЬТАТЫ:

  • ✅ "Действительна" (зеленый) - сессия активна и работает
  • ❌ "Недействительна" (красный) - сессия устарела или повреждена
  • ⚠️ "Не удалось проверить" - ошибка при проверке

РЕКОМЕНДАЦИИ:

  • ✓ Проверяйте аккаунты после длительного простоя
  • ✓ Используйте перед запуском массовых рассылок
  • ✓ Если сессия недействительна - переподключите аккаунт
  • ✓ Регулярная проверка помогает выявить заблокированные аккаунты
  • ✓ Проверка всех аккаунтов может занять время - наберитесь терпения

ЧТО ПРОВЕРЯЕТ:

РЕЗУЛЬТАТЫ:

  • ✅ "Работает" (зеленый) - прокси функционирует нормально
  • ❌ "Не работает" (красный) - прокси недоступен или неверно настроен

РЕКОМЕНДАЦИИ:

  • ✓ Проверяйте прокси перед массовыми операциями
  • ✓ Регулярно тестируйте прокси на работоспособность
  • ✓ Заменяйте неработающие прокси сразу после обнаружения
  • ✓ Используйте качественные прокси для стабильной работы
  • ✓ Проверка прокси может занять время - не прерывайте процесс

  • ✓ Рекомендуем использовать ГЕО прокси под ГЕО аккаунта

🔄 ПРОВЕРИТЬ НА СПАМБЛОК

ОПИСАНИЕ:

Обновляет статус спамблока для выбранных аккаунтов через взаимодействие с официальным ботом @SpamBot. Это наиболее точный способ определения реального статуса аккаунта в Telegram.

ЧТО ПРОВЕРЯЕТ:

  • Наличие временных ограничений (frozen/limited)
  • Наличие вечного спамблока
  • Наличие геоспамблока

РЕЗУЛЬТАТЫ:

  • ✅ "Нет ограничений" (зеленый) - аккаунт полностью активен
  • ❄️ "Заморожен" (оранжевый) - временные ограничения до определенной даты
  • 🚫 "Спамблок" (красный) - вечный спамблок
  • 🌍 "ГеоСпамБлок" (синий) - блокировка при регистрации

РЕКОМЕНДАЦИИ:

  • ✓ Проверяйте статус спамблока регулярно
  • ✓ Используйте перед запуском массовых рассылок
  • ✓ Замороженные аккаунты можно использовать после снятия ограничений
  • ✓ Геоспамблок обычно получают сложные ГЕО
  • ✓ Просматриваете текст сообщения от @spambot в логах, для более точного определения

🌐 УСТАНОВИТЬ ПРОКСИ

ОПИСАНИЕ:

Позволяет массово установить прокси-серверы для выбранных аккаунтов. Поддерживает различные типы прокси и автоматическое распределение по геолокациям.

ВОЗМОЖНОСТИ:

  • Выбор типа прокси: SOCKS5, HTTP, MTProto
  • Установка прокси из системы (если настроена)

ТИПЫ ПРОКСИ:

  • HTTP - для базовых задач
  • MTProto - специальный протокол Telegram
  • Нет прокси - работа без прокси (не рекомендуется)

РЕКОМЕНДАЦИИ:

  • ✓ Всегда используйте прокси для защиты аккаунтов
  • ✓ Выбирайте прокси из той же страны, что и номер телефона
  • ✓ Используйте качественные резидентные прокси
  • ✓ Регулярно проверяйте работоспособность прокси
  • ✓ Не используйте один прокси для большого количества аккаунтов
  • ✓ Распределяйте аккаунты по разным прокси для безопасности
  • ✓ После установки прокси проверьте его работоспособность

ОТКРЫТЬ В DESKTOP

⚠️ Важно о Telegram Desktop !!!

Сообщения успешно отправляются через софт, но могут не отображаться в открытом окне Telegram Desktop сразу.

Для обновления информации в Telegram Desktop:

  1. Нажмите Ctrl+Shift+Esc (или Ctrl+Alt+Delete → Диспетчер задач)
  2. Найдите все процессы "telegram.exe"
  3. Завершите их (Правой кнопкой → Снять задачу)
  4. Запустите Telegram Desktop заново

После перезапуска все отправленные сообщения будут видны.

РАЗДЕЛ 1: ДОБАВЛЕНИЕ ПРОКСИ

1.1. КНОПКА "ДОБАВИТЬ ПРОКСИ" (➕)

ОПИСАНИЕ:

Массовое добавление прокси-серверов в систему. Поддерживает добавление нескольких прокси одновременно, каждый на отдельной строке.

ПАРАМЕТРЫ:

  • Папка для сохранения
    • Выбор папки, куда будут добавлены прокси
    • Можно выбрать существующую (или создать новую) папку или "Общий список"
    • Прокси можно организовать по папкам для удобства
  • Протокол прокси
    • SOCKS5 (рекомендуется) - универсальный протокол
    • SOCKS4 - устаревший протокол
    • HTTP - базовый протокол
    • MTProto (Telegram) - специальный протокол для Telegram
  • Формат прокси (для HTTP и SOCKS5)
    • логин:пароль:хост:порт
    • логин:пароль@хост:порт
    • хост:порт:логин:пароль (по умолчанию)
    • хост:порт@логин:пароль
  • Список прокси
    • Ввод прокси по одному на строку
    • Поддержка различных форматов в зависимости от выбранного протокола
    • Автоматический парсинг и валидация

ФОРМАТЫ ВВОДА:

Для HTTP/SOCKS5 (с форматом):

  • хост:порт:логин:пароль
  • 192.168.1.1:1080:user:pass
  • example.com:8080:login:password

Без авторизации:

  • 192.168.1.1:1080

РЕКОМЕНДАЦИИ:

  • ✓ Используйте SOCKS5 для максимальной совместимости
  • ✓ Проверяйте формат прокси перед добавлением
  • ✓ Организуйте прокси по папкам (по странам, провайдерам и т.д.)
  • ✓ Добавляйте прокси порциями для удобства проверки
  • ✓ После добавления сразу проверяйте работоспособность

  • ✓ Организуйте прокси по странам для удобства распределения
  • ✓ Создавайте отдельные папки для разных типов прокси

2.2. КОНТЕКСТНОЕ МЕНЮ ПАПКИ (Правый клик)

ОПИСАНИЕ:

Доступ к действиям с папкой через правый клик по папке в списке.

ДОСТУПНЫЕ ДЕЙСТВИЯ:

    • Изменение названия папки

  • Удалить

    • Все прокси из папки будут перемещены в "Общий список"

РЕКОМЕНДАЦИИ:

  • ✓ Используйте переименование вместо удаления и создания новой папки
  • ✓ Перед удалением папки убедитесь, что прокси не нужны в текущей организации
  • ✓ Удаление папки не удаляет прокси, только перемещает их

РАЗДЕЛ 3: ФИЛЬТРАЦИЯ И ОРГАНИЗАЦИЯ

3.1. ВЫПАДАЮЩИЙ СПИСОК "ФИЛЬТР ПАПОК"

ОПИСАНИЕ:

Фильтрация отображаемых прокси по папкам. Позволяет просматривать прокси из конкретной папки или все прокси сразу.

ВАРИАНТЫ:

  • Все папки - показывает все прокси из всех папок
  • Общий список - показывает только прокси без папки
  • [Название папки] - показывает только прокси из выбранной папки

РЕКОМЕНДАЦИИ:

  • ✓ Используйте фильтры для быстрого поиска нужных прокси
  • ✓ Переключайтесь между папками для проверки их содержимого
  • ✓ Используйте "Все папки" для общего обзора

3.2. ВЫПАДАЮЩИЙ СПИСОК "ПЕРЕНОС В ПАПКУ"

ОПИСАНИЕ:

Выбор целевой папки для переноса выбранных прокси.

ВАРИАНТЫ:

  • Общий список - перемещение прокси из папки в общий список
  • [Название папки] - перемещение прокси в выбранную папку

3.3. КНОПКА "ПЕРЕНЕСТИ" (➡️)

ОПИСАНИЕ:

Перенос выбранных прокси в указанную папку. Позволяет реорганизовать структуру прокси.

ИСПОЛЬЗОВАНИЕ:

  1. Выберите прокси (через чекбоксы или клик по строке)
  2. Выберите целевую папку из выпадающего списка
  3. Нажмите кнопку "Перенести"

РЕКОМЕНДАЦИИ:

  • ✓ Используйте для организации прокси по категориям
  • ✓ Переносите проверенные прокси в соответствующие папки
  • ✓ Регулярно реорганизуйте структуру для удобства работы
  • ✓ Можно переносить прокси между папками или в общий список

РАЗДЕЛ 4: ПРОВЕРКА ПРОКСИ

⚠️ ВАЖНО: Для проверки прокси на серверах Telegram необходимо иметь хотя бы одну полноценно созданную tdata с сессией. Система использует API ключи из аккаунта для проверки прокси.

4.1. КНОПКА "ПРОВЕРИТЬ ВСЕ" (✓)

ОПИСАНИЕ:

Проверка работоспособности всех прокси в системе. Проверяет доступность, скорость соединения и определяет GEO (геолокацию) прокси.

ЧТО ПРОВЕРЯЕТ:

  • Доступность прокси-сервера
  • Скорость соединения (таймауты)
  • Возможность подключения к Telegram через прокси
  • Определение геолокации (GEO) прокси

  • Оба условия должны быть выполнены перед отправкой

РЕКОМЕНДАЦИИ:

  • ✓ Рекомендуется: 3-10 секунд для избежания блокировки
  • ✓ Минимальная задержка: не менее 1 секунды
  • ✓ Для больших рассылок: 5-15 секунд
  • ✓ Для безопасности: 10-20 секунд
  • ✓ Случайная задержка имитирует человеческое поведение
  • ⚠️ Слишком маленькая задержка может привести к блокировке

5.2. ЗАДЕРЖКА НА АККАУНТ (👤⏱️)

ОПИСАНИЕ:

ПАРАМЕТРЫ:

  • От (сек) - минимальная задержка на аккаунт в секундах
  • До (сек) - максимальная задержка на аккаунт в секундах
  • Диапазон: от 1 до 600 секунд
  • Опционально: если пусто, используется глобальная × 3

АВТОМАТИЧЕСКИЙ РАСЧЕТ:

  • Если поле пустое, используется формула: глобальная задержка × 3
  • Например: глобальная 5-10 сек → per-account 15-30 сек
  • Можно задать вручную для точного контроля

РЕКОМЕНДАЦИИ:

  • ✓ Рекомендуется: 30-90 секунд между отправками одного аккаунта
  • ✓ Для безопасности: 60-120 секунд

  • ⚠️ Слишком маленькая задержка может привести к блокировке аккаунта

5.3. РЕЖИМ РАСПРЕДЕЛЕНИЯ АККАУНТОВ (🔄)

ОПИСАНИЕ:

Выбор режима распределения аккаунтов по группам. Определяет, как аккаунты будут работать с группами.

ДОСТУПНЫЕ РЕЖИМЫ:

  • 1. "Аккаунты по кругу по всем группам" (рекомендуется)
    • Каждый аккаунт отправляет сообщение в следующую группу по кругу
    • Равномерное распределение нагрузки
    • Максимальная эффективность
    • Пример: Аккаунт 1 → Группа 1, Аккаунт 2 → Группа 2, Аккаунт 3 → Группа 3, Аккаунт 1 → Группа 4, Аккаунт 2 → Группа 5...
  • 2. "Один аккаунт → все группы"
    • Один аккаунт отправляет сообщения во все группы последовательно
    • Затем следующий аккаунт отправляет во все группы
    • Подходит для небольших списков групп
    • Пример: Аккаунт 1 → все группы, затем Аккаунт 2 → все группы...
  • 3. "Все аккаунты → одна группа"
    • Все аккаунты отправляют сообщения в одну группу
    • Затем переходят к следующей группе
    • Подходит для важных групп
    • Пример: Все аккаунты → Группа 1, затем все аккаунты → Группа 2...
  • 4. "1 аккаунт = 1 группа (фикс)"
    • Каждый аккаунт закреплен за одной группой
    • Один аккаунт работает только с одной группой
    • Подходит для равного количества аккаунтов и групп
    • Пример: Аккаунт 1 → Группа 1, Аккаунт 2 → Группа 2...

РЕКОМЕНДАЦИИ:

  • ✓ Используйте "Аккаунты по кругу" для большинства случаев
  • ✓ "Один аккаунт → все группы" для небольших списков
  • ✓ "Все аккаунты → одна группа" для важных групп
  • ✓ "1 аккаунт = 1 группа" для равного распределения
  • ✓ Выбор режима зависит от количества аккаунтов и групп

  • ✓ Проверяйте корректность ссылки перед запуском

2. АККАУНТЫ ДЛЯ ПАРСИНГА

2.1. СПИСОК АККАУНТОВ

ОПИСАНИЕ:

Выберите один или несколько авторизованных аккаунтов, которые будут парсить участников. При нескольких аккаунтах нагрузка распределяется между ними по кругу.

2.2. КНОПКИ "ВЫБРАТЬ ВСЕХ / СНЯТЬ ВЫБОР"

ОПИСАНИЕ:

Быстро выделить или снять выделение со всех доступных аккаунтов.

РЕКОМЕНДАЦИИ:

  • ✓ Для небольших задач (до 2–3 тыс. участников) достаточно 1 аккаунта
  • ✓ Для больших задач подключайте 2–3 аккаунта, но не все сразу, чтобы не ловить лимиты

3. ОСНОВНЫЕ НАСТРОЙКИ ПАРСИНГА

3.1. ЛИМИТ УЧАСТНИКОВ

ОПИСАНИЕ:

Сколько всего участников нужно собрать.

РЕКОМЕНДАЦИИ:

  • ✓ Пример: 200–1000 участников — безопасный старт
  • ✓ Не ставьте лимиты сильно выше реальной задачи
  • ✓ Если лимит общий = 200, а «с аккаунта за круг» = 600–1000 — софт сам обрежет до 200

3.2. УЧАСТНИКОВ С ОДНОГО АККАУНТА ЗА КРУГ (от / до)

ОПИСАНИЕ:

Сколько участников один аккаунт берёт за одну «итерацию» (ОДИН запрос к API). Значение выбирается случайно в этом диапазоне.

ПРИМЕР:

  • От 600 до 1000

РЕКОМЕНДАЦИИ:

  • ✓ Используйте разумные значения для избежания лимитов
  • ✓ Софт автоматически обрежет до общего лимита, если нужно

4. ЗАДЕРЖКИ

4.1. ЗАДЕРЖКА МЕЖДУ АККАУНТАМИ (сек) (от / до)

ОПИСАНИЕ:

Пауза между работой разных аккаунтов внутри одного круга. Работает, когда выбрано 2+ аккаунтов.

РЕКОМЕНДАЦИИ:

  • ✓ Рекомендуется: 10–30 секунд
  • ✓ Используйте для распределения нагрузки между аккаунтами

4.2. ЗАДЕРЖКА МЕЖДУ КРУГАМИ (минуты)

ОПИСАНИЕ:

Пауза между циклами, когда все аккаунты один раз отработали. Это главный защитный механизм от лимитов Telegram.

РЕКОМЕНДАЦИИ:

  • ✓ Рекомендуется: 5–15 минут
  • ✓ Это основной механизм защиты от блокировок
  • ✓ Не уменьшайте слишком сильно, чтобы не получить лимиты

5. РЕЖИМ "ТОЛЬКО ТЕ, КТО ПИСАЛ СООБЩЕНИЯ"

5.1. ЧЕКБОКС "ТОЛЬКО ТЕ, КТО ПИСАЛ СООБЩЕНИЯ В ГРУППЕ"

ОПИСАНИЕ:

В этом режиме парсер сначала анализирует сообщения, собирает авторов, и возвращает только тех, кто реально писал.

ПРИ ВКЛЮЧЕНИИ ПОЯВЛЯЮТСЯ ДОПОЛНИТЕЛЬНЫЕ ПОЛЯ:

  • «Глубина проверки сообщений (общая)»
    • Сколько последних сообщений смотреть по всему чату (например, 3000)
  • «Кол-во сообщений с одного аккаунта за круг» (от / до)
    • Сколько сообщений за один раз проверяет один аккаунт
    • Софт идёт по сообщениям подряд, без пропусков (акк1 — первые сообщения диапазона, акк2 — следующие и т.д.)

РЕКОМЕНДАЦИИ:

  • ✓ Используйте этот режим, если нужны более «живые» пользователи, которые что‑то писали в чате
  • ✓ Не ставьте слишком большую глубину на маленьких группах, чтобы не тратить лишние запросы

6. ФИЛЬТРЫ

ОПИСАНИЕ:

Все фильтры можно комбинировать. В итоговый список попадают только те, кто подходит под ВСЕ выбранные условия.

6.1. "ТОЛЬКО АКТИВНЫЕ ПОЛЬЗОВАТЕЛИ (были в сети недавно, не старше 7 дней)"

ОПИСАНИЕ:

Оставляет только тех, кто был онлайн не позднее 7 дней назад. Убирает статусы «LastWeek» и «LastMonth», а также слишком старые `LastSeenOffline`.

6.2. "ТОЛЬКО С НОМЕРОМ ТЕЛЕФОНА (если доступен)"

ОПИСАНИЕ:

Оставляет только тех, у кого есть открытый телефон. Телефон будет записан в формате `+7...`.

6.3. "ПАРСИТЬ УЧАСТНИКОВ ТОЛЬКО С @username"

ОПИСАНИЕ:

Оставляет только тех, у кого есть `username`. Работает и в обычном режиме, и в режиме «Только те, кто писал сообщения».

6.4. "ПРОПУСТИТЬ БОТОВ"

ОПИСАНИЕ:

Убирает все аккаунты, у которых `bot = True`.

ПРИМЕРЫ КОМБИНАЦИЙ:

  • Только реальные люди с username:
    • Включить: `Пропустить ботов` + `Парсить участников только с @username`
  • Активные лиды для рассылки в ЛС:
    • Включить: `Только активные` + `Только с номером телефона` (опционально) + `Пропустить ботов`

7. КАК РАБОТАЕТ ПАРСИНГ (КРАТКО)

ПРОЦЕСС:

  1. Вы выбираете группу, аккаунты, лимиты и фильтры
  2. Софт по кругу обходит аккаунты и делает по одному запросу к API на аккаунт за круг, соблюдая задержки
  3. Сначала собираются «сырые» участники из Telegram
  4. Затем к каждому участнику применяются все включённые фильтры
  5. В UI показываются:
    • Всего спарсено — сколько пользователей прошло все фильтры
    • С username — сколько с `@username`
    • С телефоном — сколько с номером
  6. Результаты можно сразу выгрузить в CSV / TXT / JSON

РЕКОМЕНДАЦИИ ПО БЕЗОПАСНОСТИ

  • ✓ Не запускайте парсер слишком часто по одной и той же группе
  • ✓ Держите разумные задержки между кругами (5–15 минут)
  • ✓ Не включайте все фильтры сразу без необходимости — это может сильно уменьшить итоговое количество
  • ✓ Всегда сначала протестируйте на маленьком лимите (100–200 участников), прежде чем запускать большие задачи

Парсер ЛС

Этот модуль собирает пользователей из личных сообщений (диалогов) выбранных аккаунтов Telegram. Парсер проходит по всем диалогам аккаунта и извлекает контакты, с которыми есть история переписки.

ПРИНЦИП РАБОТЫ

  1. Вы выбираете один или несколько аккаунтов для парсинга
  2. Софт подключается к каждому аккаунту и получает список всех диалогов (личных сообщений)
  3. Из каждого диалога извлекается информация о пользователе:
    • User ID (обязательно)
    • Username (если есть)
  4. Автоматически пропускаются:
    • Боты
    • Сам аккаунт (себя)
    • Группы и каналы (только личные диалоги с пользователями)
  5. Результаты группируются и показываются в интерфейсе
  6. После завершения можно скачать результаты в формате TXT

НАСТРОЙКИ

1. ВЫБОР АККАУНТОВ ДЛЯ ПАРСИНГА

1.1. СПИСОК АККАУНТОВ

ОПИСАНИЕ:

Выберите один или несколько авторизованных аккаунтов, которые будут парсить свои личные сообщения. Каждый аккаунт парсит только свои диалоги (тех, с кем он переписывался).

1.2. КНОПКИ "ВЫБРАТЬ ВСЕХ / СНЯТЬ ВЫБОР"

ОПИСАНИЕ:

Быстро выделить или снять выделение со всех доступных аккаунтов.

РЕКОМЕНДАЦИИ:

  • ✓ Для одного аккаунта парсинг обычно занимает несколько секунд или минут (зависит от количества диалогов)
  • ✓ При выборе нескольких аккаунтов они обрабатываются последовательно с задержкой между ними

2. ЗАДЕРЖКА МЕЖДУ АККАУНТАМИ

2.1. ПОЛЯ "ОТ (СЕК)" / "ДО (СЕК)"

ОПИСАНИЕ:

Случайная задержка между обработкой разных аккаунтов (в секундах). После завершения парсинга одного аккаунта делается пауза, затем начинается парсинг следующего.

ПО УМОЛЧАНИЮ:

  • 2-5 секунд

РЕКОМЕНДАЦИИ:

  • ✓ Для 1-2 аккаунтов можно оставить минимальные задержки (2-5 сек)
  • ✓ При большом количестве аккаунтов (5+) увеличьте задержку до 5-10 секунд для безопасности

РЕЗУЛЬТАТЫ ПАРСИНГА

После завершения парсинга отображаются статистика:

  • Всего найдено — общее количество уникальных пользователей из всех диалогов
  • С username — сколько пользователей имеют @username
  • Только ID — сколько пользователей без username (только ID)

ПРИМЕЧАНИЕ:

  • Если один и тот же пользователь есть в диалогах нескольких аккаунтов, он считается один раз (уникальные пользователи)
  • Результаты можно скачать в формате TXT для дальнейшего использования

КАК РАБОТАЕТ ПАРСИНГ (ПОШАГОВО)

  1. Вы выбираете аккаунты и настраиваете задержку
  2. Нажимаете «Начать парсинг»
  3. Софт последовательно подключается к каждому выбранному аккаунту:
    • Получает список всех диалогов аккаунта
    • Проходит по каждому диалогу
    • Извлекает информацию о пользователе (ID, username)
    • Пропускает ботов, группы, каналы и самого себя
  4. После обработки одного аккаунта делается пауза (задержка)
  5. Затем обрабатывается следующий аккаунт
  6. Все найденные пользователи собираются в общий список (без дублей)
  7. По завершении показываются результаты и кнопка «Скачать результаты (TXT)»

ПРОГРЕСС ПАРСИНГА

Во время работы отображается:

  • Прогресс-бар с процентом выполнения (обработано аккаунтов / всего аккаунтов)
  • Статистика в реальном времени:
    • Всего найдено
    • С username
    • Только ID
  • Логи процесса с информацией о каждом этапе

После завершения блок прогресса автоматически скрывается, остаются только финальные результаты.

РЕКОМЕНДАЦИИ ПО БЕЗОПАСНОСТИ

  • ✓ Не запускайте парсинг слишком часто с одних и тех же аккаунтов
  • ✓ Используйте разумные задержки между аккаунтами (особенно при большом количестве)
  • ✓ Парсинг личных сообщений — относительно безопасная операция, но не злоупотребляйте
  • ✓ Если у аккаунта очень много диалогов (тысячи), парсинг может занять больше времени

ОТЛИЧИЯ ОТ ПАРСЕРА УЧАСТНИКОВ

  • Парсер участников собирает пользователей из групп/каналов
  • Парсер ЛС собирает пользователей из личных диалогов аккаунта
  • В парсере ЛС нет фильтров (активность, телефон и т.п.) — собираются все контакты из диалогов
  • Парсер ЛС работает быстрее, так как не нужно делать запросы к группам

ПРИМЕНЕНИЕ

Парсер ЛС полезен для:

  • Сбора контактов из личных переписок для рассылок
  • Создания базы контактов из диалогов аккаунта
  • Анализа списка людей, с которыми велась переписка
  • Экспорта контактов для дальнейшей работы в других модулях
