Новое
Добавили отметку пользователей в рассылке по группам
  • Список @username для отметок
  • Количество отметок в сообщении: диапазон "от/до" (берется случайное значение из диапазона)
  • Опция "Скрыть @username в тексте"
Пофиксили скрытие текста в рассылках
  • Рассылка по группам: скрытие работает для:
    • ручного текста в формате ||скрытый текст||
    • @username в тексте (при включенном переключателе)
    • блока добавленных отметок (при включенном переключателе)
  • Рассылка в ЛС: скрытие текста ||...|| приведено к тому же механизму, что и в рассылке по группам
Отчеты по рассылке по группам
  • Добавлен блок "Не отмеченные пользователи" в отчете
  • При остановке рассылки по кнопке "Остановить" отчет формируется сразу
